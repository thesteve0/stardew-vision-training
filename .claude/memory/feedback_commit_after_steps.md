Ask the user if they want to git commit and push after each step of a plan is completed.

**Why:** User wants granular control over what gets committed and when, rather than batching changes.

**How to apply:** After finishing each discrete step in an implementation plan, pause and ask "Want me to commit and push these changes?" before moving to the next step.
